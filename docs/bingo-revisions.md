## 差し替えの基準

ビンゴの項目は順位を持つページの本文なので、現行を残して部分改訂にした（decisions Q7）。差し替えたのは、次のどれかに当たる項目だけ。迷ったものは残した。

1. トーンガイドの流行語・誇張語（「ヤバい」「ガチ」「秒で」「最強」など）
2. すぐ古びるネットスラング（「〜厨」「カンスト」「バグ」など）
3. 人を見下す言い方（「無能」「バカ」）
4. 死や心の不調を軽く使う言い方（「〜ないと死ぬ」「ヒステリック」）
5. 性別の決めつけ

差し替え後の項目は、元のあるあるの中身を残した。件数は全タイプ24のまま、並びも変えていない。
