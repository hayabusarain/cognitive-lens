### 2-1. トーンガイド（`docs/tone-guide.md` の内容）

- ユーザー本人には敬語、タイプ説明は断定寄り。「〜しがち」「心当たりあるはず」のように当てにいく語尾
- 若者言葉・流行語は使わない（1年で古びる）。`check-banned-terms.mjs` に流行語も登録
- 1文を短く。3行以上の段落を作らない
- 褒めと図星を交互に。短所は「欠点」ではなく「あるある」として書く
- 誇張語（最強・天才・神・完璧）は使わない

## 3. 呼称（16タイプ）

| TYPE | 呼称 | 由来 |
|---|---|---|
| INTJ | スフィンクス | 謎を出す側、動かず先を読む |
| INTP | リヴァイアサン | 深海に潜む巨大な思考 |
| ENTJ | ドラゴン | 群れを率いる |
| ENTP | キマイラ | 異物の組み合わせ、予測不能 |
| INFJ | ユニコーン | 稀少、真実を見抜く |
| INFP | ペガサス | 自分の空を飛ぶ |
| ENFJ | フェニックス | 人を照らし立ち直らせる |
| ENFP | ピクシー | いたずらな火花、巻き込む |
| ISTJ | ゴーレム | 命じられたことを崩さず守る |
| ISFJ | グリフォン | 宝を守る番人 |
| ESTJ | ケルベロス | 門番、秩序 |
| ESFJ | ドライアド | 森の集まる場所、世話役 |
| ISTP | フェンリル | 一匹狼、一撃で終わらせる |
| ISFP | マーメイド | 感性、自分の海で歌う |
| ESTP | ミノタウロス | 考える前に突進 |
| ESFP | サラマンダー | 火のまわりに人が集まる |

- 系統：NT＝古代の怪物、NF＝光る生き物、SJ＝番人、SP＝野生
- 表記は幻獣名のみ（「〜型」は付けない）
- **h1 は型コードを主、幻獣名を副題**（検索は型コードで取り、幻獣名はシェア用）
- `lib/type-names.ts` に登録。決定後に `check-banned-terms.mjs` → ウェブ調査 → J-PlatPat → `docs/naming-check.md` の順で確認

## 4. キャラ画像の作り直し

| 項目 | 内容 |
|---|---|
| コンセプト | 幻獣そのものではなく**幻獣を纏った人型キャラ**。角・翼・鱗・毛皮など幻獣要素を1〜2点 |
| 仕様 | 800×1000、透過 PNG（現行と同じ。パイプラインを変えない） |
| 作り方 | 1本のスタイル指示で16枚を一気に生成（ばらつき防止） |
| 記録 | `docs/asset-credits.md` にツール名・日付・プロンプトを残す |
| 進め方 | 実装は現行画像のまま進める。画像はパス管理なので完成後に差し替えるだけ |
