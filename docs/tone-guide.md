# CognitiveLens 文章トーンガイド

想定読者：サイトの文章を書く人（運営者と、このリポジトリで作業する AI）
作成日：2026-09-15　状態：**運営者のレビュー待ち**（仕様書ステップ 2-1）
元にした決定：`docs/decisions.md` 2-1、N3、N4、N9、N11

このガイドは、16タイプの説明文・設問・ビンゴ・コラム・画面の文言など、サイトに載る日本語すべてに使う。数えられる決まりは `scripts/check-content.mjs` と `scripts/check-banned-terms.mjs` がビルドの前に検査する。

---

## 1. 読者

16〜24歳。スマートフォンで、診断の結果やビンゴを友達に見せる前提で読む。

## 2. 誰に向けて、どの語尾で書くか

| 場所 | 語尾 | 例 |
|---|---|---|
| 利用者本人への案内（ボタン、操作の説明、エラー、規約） | 敬体（です・ます） | 結果画像を保存できます |
| タイプの説明（特徴、恋愛、仕事、すれ違い） | 常体で言い切る。当てにいく語尾を使う | 予定が崩れると、顔には出さなくても一日引きずりがち |
| 設問 | 常体の短い文 | 予定のない休日は、一人で過ごしたい |

タイプの説明は「〜しがち」「心当たりがあるはず」「〜なタイプ」のように、読者が「当たってる」と感じる言い方にする。「〜かもしれません」「〜の可能性があります」でぼかさない。

同じ語尾を2文続けない。「〜しがち。〜しがち。」と並べると、中身が具体的でも単調に読める。

二人称は「あなた」。相手診断から来た結果ページでは「あの人」にする（仕様書 2-3）。

## 3. 長さ（機械で検査する）

- 1文は45字以内
- 1段落は120字以内、かつ3文以内
- タグラインと OG 画像の短文は24字以内
- 設問は45字以内

段落は改行で、文は「。」「！」「？」で区切って数える。スマートフォンでの表示行数は端末で変わるので、文字数で決めている（decisions N4）。

情報を足したくなったら、文を分ける。「ただし」「つまり」「そのため」でつながない。

## 4. 褒めと図星

褒める文と図星を指す文を交互に置く。どちらかが続くと、持ち上げすぎか悪口に読める。

短所は「欠点」として書かず、「あるある」として書く。読んだ本人が笑って友達に見せられる温度にする。

- ✗ 協調性がなく、周りから浮きやすい
- ✓ 会議で「それ、必要ですか」と聞いてしまい、空気が一瞬止まる。でも後で「助かった」と言われるのもこのタイプ

## 5. 使わない言葉

### 5-1. 流行語・若者言葉

1年で古びるので使わない。次の語は `check-banned-terms.mjs` に登録している。見出し・呼称・タグラインに出たらビルドが止まり、本文に出たら警告が出る。

ヤバい、ヤバ、ガチ、ガチ勢、マジ、エモい、エモ、沼る、沼、蛙化、ぴえん、それな、草、陰キャ、陽キャ、メンヘラ、無理ゲー、詰んだ、秒で、爆速、エグい、ワンチャン、知らんけど、神対応、神機能、チート、デフォ、アプデ、裏アカ、量産型、限界突破

この一覧は筆者の案で、**運営者のレビューで足し引きする**。「推し」「地雷を踏む」「優勝」は一般の言葉として使う場面が多いので、一覧に入れていない。

### 5-2. 誇張語

最強、天才、神、完璧。データで裏付けられない言い切りになるため使わない（仕様書 6-1）。

### 5-3. 既存の型分類に由来する名前

16Personalities と Keirsey の型名・グループ名、現行サイトの型名は使わない。一覧は仕様書 6-1 にある。呼称の系統名（古代の怪物・光る生き物・番人・野生）もサイトに出さない（decisions N2）。

### 5-4. 「MBTI」の語

検索結果に出る要素（title・description・h1）とサイト名には使わない。例外はビンゴのハブ `/ja/bingo` だけ。本文では「MBTIでいうINTJ」のような説明として、1ページ1回まで書いてよい（decisions N3・N11）。

### 5-5. 人や職業を見下す言い方

職業名や属性を、からかう形容で書かない。「下っ端の事務」「ゴリゴリ営業」「ブラック企業」は、中立な言い方に直す（decisions N9）。

性別で決めつけない。「メンヘラ」のように、心の不調を指す言葉を性格の説明に使わない。

一方で、毒を抜きすぎて求人票のような文にもしない。「成果主義の強い外資系企業」は中立だが、全部がこの調子だと読む楽しさがなくなる。

## 6. 言い切ってよいこと、よくないこと

タイプの傾向は言い切る。性格タイプは傾向を楽しむためのもので、本人を決めつけるものではない、という前提は規約と免責のページに書く。

「科学的に証明された」「必ず当たる」のように、裏付けのない根拠を示す言い方はしない。

## 7. 書いた後に見ること

1. `npm run check` を実行し、長さ・禁止語・件数の違反をなくす
2. 声に出して読み、同じ語尾が続いていないか、接続詞でつないでいないかを見る
3. 褒めと図星が交互になっているかを見る
4. 自分がそのタイプだとして、友達に見せたくなるかを考える
